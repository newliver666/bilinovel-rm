# bilinovel-rm

哔哩轻小说 Android 客户端 · 无广告版本

基于官方客户端制作，去除了应用内的广告展示，界面与操作和原版完全一致。

---

## 关于

| 项目 | 说明 |
|---|---|
| 应用名称 | 哔哩轻小说 |
| 包名 | `com.linovelib.bilinovel` |
| 版本 | 1.75.52 |
| 支持系统 | Android 8.1 (API 27) 及以上 |
| 支持架构 | 通用（arm64-v8a / armeabi-v7a / x86_64） |

## 已做优化

- 移除启动时的开屏广告
- 移除阅读页底部的横幅广告
- 阅读界面干净无广告占位，正文区域完整保留
- 不弹出「强制更新」提示，可长期停留在当前版本使用

广告以外的功能均保持原样：登录、注册、书城、排行榜、搜索、书架、阅读、书评、圈子、个人中心等全部正常使用。

## 安装

**方式一：直接下载（推荐）**

点这里下载 → **[bilinovel-1.75.52-no-ads.apk](../../releases/download/v1.75.52/bilinovel-1.75.52-no-ads.apk)**

下载完成后在手机上打开该文件，系统提示「未知来源应用」时允许本次安装即可。

**方式二：从 Releases 页面**

1. 前往本仓库的 [Releases](../../releases) 页面
2. 在最新版本的 Assets 中下载 `.apk` 文件
3. 在手机上打开该文件，允许「未知来源应用」后完成安装

## 使用说明

- **网络**：书城和阅读内容需要联网加载。首次打开如果首页是空白，请检查网络是否正常（部分网络环境需要代理才能访问服务端）。网络恢复后重进应用即可
- **登录**：在「我的」页面点击「立即登录」，使用哔哩轻小说账号登录。登录后书架、阅读记录、积分等会同步
- **书架**：书籍详情页点击「加书架」，即可在书架中快速找到
- **阅读设置**：阅读界面内可调整字号、行距、背景色等，与官方版一致

## 常见问题

**安装失败 / 提示签名不一致？**

本版本使用独立签名，与官方版无法互相覆盖安装。请先卸载已安装的官方版本，再安装本版本。

**安装后需要重新登录？**

是的。卸载旧版会同时清除本地登录状态，用账号重新登录一次即可，登录后的数据都在服务端，不会丢失。

**首页加载不出来？**

确认网络可以正常访问 `api.readpai.com`。若所在网络需要代理，请先开启代理再启动应用。

**会不会提示更新？**

不会。当前版本已处理更新提示，可以一直使用。
